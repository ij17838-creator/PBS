# 개인정보·보안 안내 (PBS 행동 관찰 기록장)

2026-11-24 작성. 앱 안 '설정 > 개인정보 안내'와 같은 내용을 교사·관리자·후원 기관이 볼 수 있게 자세히 적은 문서입니다.

## 1. 원칙: 학생 코드만
- 프로젝트 이름은 **학생 코드**(예: 3-2-A)만 씁니다. 이름 칸이 없고, 새 프로젝트에서 한글 이름(2~4자)처럼 보이는 코드를 쓰면 '이름 같아요 · 코드 권장'이 뜹니다(막지는 않음).
- 메모·ABC 기록·보고서에도 이름, 생년월일, 학번, 주소, 연락처, 진단명 전체 문서를 적지 않습니다. 다른 학생은 '또래 A'처럼 씁니다.
- 얼굴이 나온 사진은 올리지 않습니다.

## 2. 무엇이 어디에 저장되나

| 자료 | 저장 위치 | 비고 |
|---|---|---|
| 공유하지 않은 프로젝트 | 이 기기(브라우저·앱 저장소)에만 | 서버로 가지 않음 |
| 공유 프로젝트의 글·선택값·손글씨 | 기기 + 서버(Google Firebase Firestore) | 2026-11-24부터 손글씨도 서버로 |
| 녹음·사진·첨부 파일 | 이 기기에만 | 백업 파일에 넣을 수 있음 |
| 앱 설정(색·켜고 끄는 옵션) | 로그인 계정(users/{uid}/prefs) | 학생 자료 아님 |
| AI 도우미에 보낸 내용 | Google AI(Firebase AI Logic) | 버튼을 누를 때만, 그 절차 내용만 |

- 위 막대의 상태 점을 누르면 '지금 상태' 창에서 **이 기기 저장**과 **서버 저장**을 따로 볼 수 있습니다. 공유 프로젝트의 회기·관찰지 머리에는 '서버 저장' / '이 기기에만'이 붙습니다.
- Firestore 위치(리전)는 Firebase 콘솔 > Firestore Database에서 확인합니다.

## 3. 누가 볼 수 있나 (서버 규칙 `firestore.rules`)
- 프로젝트 자료(칸·목록·수정 기록·충돌)는 **멤버만** 읽고 씁니다. 멤버가 되려면 공유 ID와 공유 코드를 둘 다 알아야 합니다(코드는 SHA-256으로 바꿔 저장, 목록 보기 막음).
- 프로젝트 목록 전체 보기(list)는 아무도 못 합니다.
- 소유자만 공유 코드를 바꾸고 멤버를 내보냅니다. 멤버를 내보낸 뒤에는 공유 코드도 바꾸세요.
- 수정 기록은 추가만 되고 고칠 수 없습니다.
- 각 사용자 정보(users/{uid})는 본인만 읽고 씁니다.
- 앱 화면의 로그인 이메일은 `ij1***@gmail.com`처럼 가려 보이고, 누르면 8초 동안만 전체가 보입니다(칠판·화면 공유 때 노출 줄이기).
- 다른 멤버에게는 이메일이 아니라 '표시 이름'만 보입니다. 표시 이름은 공유 카드에서 바꿀 수 있습니다.

### 2026-11-24 규칙 점검 결과
- 문제: 소유자가 공유 프로젝트를 지워도 서버에는 '삭제됨' 표시만 남고 기록 전체가 계속 남았습니다(규칙이 삭제를 모두 막음).
- 고침: 소유자가 먼저 '삭제됨'으로 표시한 프로젝트에 한해, 소유자만 칸·목록·수정 기록·충돌 문서와 프로젝트 문서를 지울 수 있게 했습니다(`ownerPurging`). 멤버는 여전히 아무것도 지울 수 없습니다(에뮬레이터에서 거절 확인).
- **사용자가 할 일**: Firebase 콘솔 > Firestore Database > 규칙 탭에 저장소의 `firestore.rules` 내용을 붙여 넣고 '게시'. 게시 전에는 앱이 예전처럼 '삭제됨' 표시만 남기고 그 사실을 알려 줍니다.

## 4. 보관과 삭제
- 권장: 지원(학기·연구)이 끝나면 **백업을 내보낸 뒤 프로젝트를 삭제**합니다.
- 소유자가 공유 프로젝트를 삭제하면: 서버 자료 전체 삭제(새 규칙 게시 후) + 멤버 기기의 사본도 삭제.
- 멤버가 삭제하면: 그 기기에서만 지워지고 서버와 다른 사람 자료는 그대로입니다.
- 녹음은 다시 세어 확인(혼자 하는 관찰의 일치도 확인)한 뒤 지웁니다.
- 내보낸 백업 파일·CSV·PDF는 학교 개인정보 보관 규정에 따라 보관하고 기간이 지나면 지웁니다.

## 5. 내보내기
- 목록 화면 '전체 백업 내보내기': 모든 프로젝트(녹음 포함 선택) JSON 파일. '백업 불러오기'로 되살림.
- 프로젝트 화면 '이 프로젝트 백업'.
- ABC 관찰 요약 'CSV 내보내기(엑셀)'.
- 최종 보고서: 인쇄 → PDF로 저장.

## 6. 보호자 동의 안내 문구(예시)
앱 '개인정보 안내' 창에서 복사할 수 있습니다. 학교 양식에 맞춰 고쳐 쓰세요.

> 우리 학급에서는 학생의 행동 지원을 위해 수업 중 행동을 관찰·기록합니다. 기록에는 학생 이름 대신 학생 코드만 쓰며, 함께 지원하는 교직원만 볼 수 있습니다. 기록은 지원 기간이 끝나면 지웁니다. 관찰 중 녹음은 교사 기기에만 두고, 다시 세어 확인한 뒤 지웁니다. 동의하지 않으셔도 불이익은 없으며, 언제든 동의를 거둘 수 있습니다.

녹음을 하거나 AI 도우미를 쓸 계획이면 동의서에 따로 적는 것을 권합니다(예: "관찰 기록 일부를 요약하기 위해 학생 코드만 들어간 글을 Google AI 서비스로 보낼 수 있습니다").

## 7. 남은 과제
- 서버 자료 자동 보관 기한(예: 1년 지나면 알림)은 아직 없습니다.
- 서버 접속 기록(누가 언제 읽었는지)은 Firebase 기본 기능 밖이라 남지 않습니다.
- 학교·교육청 개인정보 처리 지침과 맞는지는 담당자 확인이 필요합니다.
