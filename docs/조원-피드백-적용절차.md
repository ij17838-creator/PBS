# 조원 피드백 정리 · 적용 절차 (2026-11-27)

출처: `이명노의 피드백.hwp`(5개, 이하 **명노**) · `피드백.hwpx`(5개, 이하 **조원 B**). 모두 10개.
코드는 아직 안 고침. 사용자가 고른 작업 번호만 아래 절차대로 한다.

## 1. 비슷한 성향끼리 묶기

| 묶음 | 피드백 | 한 줄 요약 |
|---|---|---|
| ① 화면 넘기기·버튼 | B1 ABC·중재 계획에 '다음' 버튼 / B2 전체 보기 뒤 아래 버튼 사라짐 / B5 '마지막 절차' 대신 종합 결과 | 묶음 이동 줄(아래 `‹ 1/6 ›`)이 화면마다 들쭉날쭉 |
| ② 기초선 회기 기록 | 명노1 삭제 확인이 맨 아래에 뜸 / 명노3 '+ 회기 추가'가 1회기로 들어감 | 회기 칸 사용 중 헷갈림·오류 |
| ③ 안내 문구·척도 | 명노2 '5회기 권장' → 3~5회기 / 명노5 "아래 칸에 넣기"가 안 보임 / 명노4 QABF X·0~3 → 1~5 | 문구가 실제 화면·현장 기준과 어긋남 |
| ④ 화면 보기(고대비·색) | B3 고대비 켜고 끄기·흰 바탕·앱 색·글씨색 | 보기 설정 |
| ⑤ 측정 진행 창 | B4 '측정 시작' → 새 창에 타이머(관찰 시간)+＋1 | 회기 중 세기 화면 |

## 2. 이미 있는지 확인 결과

| 번호 | 지금 상태 | 원인·근거(코드) | 판단 |
|---|---|---|---|
| 명노3 | **오류 맞음** | `blSorted`가 날짜→시작 시각 순. '+ 회기 추가'(`actions['ses-add']`→`blNew`)는 시작 시각을 비워 둠 → 빈 시각이 같은 날 맨 앞으로 정렬. '시작' 버튼(`swGoStart`)은 지금 시각을 넣어서 순서대로 됨 | 고침 |
| 명노1 | 없음 | `sesRow`에서 `confirmBox`가 회기 칸 **맨 끝**(알림창 기록·지속시간 칸 아래)에 붙음. 삭제 버튼은 칸 맨 위 | 고침 |
| B1 | 없음 | `pgBuild`가 묶음이 2개 미만이면 바로 끝 → 아래 이동 줄(`.pg-nav`)이 아예 안 생김. ABC·중재 계획이 이 경우 | 고침 |
| B2 | 일부 있음 | 전체 보기면 `pgPaint`가 아래 줄을 지움. 되돌리기는 위 띠 맨 끝 '한 장씩 보기'(가로로 밀어야 보임)와 설정뿐 | 고침 |
| B5 | 일부 있음 | 종합 결과 = **최종 보고서**가 이미 있음(프로젝트 화면 '보고서 보기', `rep-open`·`repHTML`). 평가 마지막 묶음 버튼은 눌리지 않는 '마지막 절차' | 버튼만 바꿈 |
| 명노5 | 있음(찾기 어려움) | '아래 칸에 넣기'(`ev-fill`)는 평가 **1번 묶음**에, 문구("위 '아래 칸에 넣기'로…", `MEMO_FIELDS.evaluate`)는 **2번 묶음** 칸에 있음. 한 장씩 보기라 '위'에 없음 | 고침 |
| 명노2 | 일부 있음 | 최소 3회기(`BL_MIN=3`)는 이미 기준. 문구가 "5회기까지 채우면 더 믿을 만"(`blJudge`, `BL_GOOD=5`) | 문구만 |
| 명노4 | 있음(설명 부족) | X·0·1·2·3은 **QABF 원척도** 그대로(`QABF_OPTS`). 1~5로 바꾸면 점수 합·비교·예전 자료가 모두 어긋남 | 척도는 유지 권장, X/0 차이 설명만 보강 |
| B3 | 대부분 있음 | 고대비는 이미 설정의 켜고 끄기 칸(`SET_ROWS` id `hc`). 고대비면 앱 색은 일부러 기본색(설정에 '고대비면 기본색' 표시). 바탕은 기기 다크/라이트를 따름 → 기기가 다크면 검은 바탕. 글씨색 바꾸기는 없음 | 새로 할 것은 선택(아래 8) |
| B4 | 일부 있음 | 따로 세는 창은 이미 있음: 회기 시작 방법 5가지(`SW_WAYS`: 화면 버튼·음량·떠 있는 아이콘·간편 측정·작은 ＋1 창). **관찰 시간 타이머는 없음** | 선택(아래 9) |

### 없앤 것·거절 목록과 겹칠 수 있는 것 (먼저 확인 필요)
- **B4 측정 시작 새 창**: 예전에 없앤 '회기 칸 작게 띄워 세기', '＋1 창 자동 띄우기', '화면 가리기'와 비슷함. 하게 되면 **자동으로 뜨지 않고 버튼으로만**, 화면 전체를 가리지 않게 해야 함.
- **B3 고대비 흰 바탕·글씨색**: 앱 색은 '민트+청록'·계정 저장으로 정해 둔 상태. 글씨색까지 바꾸면 고대비 뜻(읽기 쉬움)과 부딪힘.
- 나머지 8개는 겹치는 것 없음.

## 3. 작업 절차 (한 번호 = 한 작업, 순서대로 권장)

모두 `index.html`만 바꿈 → 공지 `k:'web'`, **앱 재시작만**(새 apk 필요 없음).
작업마다: 해당 함수만 열기 → 고치기 → Playwright로 탭(1280px)·휴대폰(390px) 확인 → `NOTICES` 맨 앞 공지 → FEATURES.md 바뀐 줄만 → HANDOFF → main.

| 순서 | 작업 | 고칠 곳 (index.html) | 할 일 | 확인 방법 |
|---|---|---|---|---|
| 1 | 명노3 회기 추가 순서 오류 | `actions['ses-add']`, `blSorted` | ① '+ 회기 추가'도 시작 시각을 지금으로 채움(`swGoStart`과 같게) ② `blSorted`에서 빈 시각은 같은 날 **맨 뒤** | 6회기 있는 상태에서 회기 추가 → '7회기'로 생기는지, 예전 빈 시각 자료 순서 |
| 2 | 명노1 삭제 확인 위치 | `sesRow`, `confirmBox` | 확인 상자를 칸 머리(삭제 버튼) 바로 아래로 옮기고 그 자리로 스크롤 | 알림창 기록 50건 있는 회기에서 삭제 누르기 |
| 3 | B1·B2 아래 이동 줄 | `pgBuild`, `pgPaint` | ① 묶음 1개짜리 절차에도 아래 줄('‹ 이전 절차 · 다음 절차 ›') ② 전체 보기에서도 아래 줄 유지, 가운데 버튼을 '한 장씩 보기'로 | ABC·중재 계획 화면, 전체 보기 ↔ 한 장씩 왕복 |
| 4 | B5 마지막 절차 → 종합 결과 | `pgPaint`(마지막 `disabled` 버튼) | '마지막 절차' 자리에 '종합 결과 보기'(`rep-open`) | 평가 마지막 묶음에서 눌러 보고서가 뜨는지 |
| 5 | 명노5 "아래 칸에 넣기" | `MEMO_FIELDS.evaluate` 문구, `viewEvaluate`, `actions['ev-fill']` | 2번 묶음 '기초선 대비 변화' 칸 바로 위에도 '자동 문장 넣기' 버튼, 문구를 "버튼을 누르면 자동 문장이 들어가요"로 | 한 장씩 보기 2번 묶음에서 바로 넣어지는지 |
| 6 | 명노2 기초선 문구 | `blJudge` | "3회기부터 판단 가능, 3~5회기면 믿을 만" 쪽으로 문구 변경(`BL_GOOD` 값은 사용자 확인 후) | 3·4·5회기 자료로 문구 확인 |
| 7 | 명노4 QABF 설명 | `QABF_OPTS`, `HELP['pg:qabf/문항']` | 척도는 그대로, X=그 상황 자체가 없음 / 0=상황은 있는데 행동 안 함 을 ⓘ·한 줄로 | 문항 화면 ⓘ |
| 8 | (선택) B3 고대비 | `SET_ROWS` id `hc`, `lookApply`, CSS `:root.hc` | 고대비 하위 옵션 '늘 흰 바탕·검정 글씨'(기본 꺼짐). 글씨색 바꾸기는 권하지 않음 | 다크 기기에서 켜고 끄기 |
| 9 | (선택) B4 관찰 시간 타이머 | `sesRow`, `swGoStart`, `miniShow` | 회기 칸 '관찰 시간(분)'으로 줄어드는 남은 시간 표시, 누를 때만 시작, 0이 되면 알림만(자동으로 창 안 띄움) | 타이머 시작·멈춤, 작은 ＋1 창에도 보이는지 |

### 사용자가 정할 것
- 6: 권장 회기 수를 3으로 할지(문구만 3~5로 할지).
- 7: 1~5로 꼭 바꿀지(권하지 않음) 아니면 설명만 보강할지.
- 8·9: 할지 말지(없앤 기능과 비슷한 점 확인).
