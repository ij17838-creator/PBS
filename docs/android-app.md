# 안드로이드 설치형 앱 (PBS 기록)

웹앱(`index.html`)을 그대로 앱 안에 넣은 설치형 앱입니다. 브라우저 주소로 쓰는 웹앱은 지금처럼 그대로 동작합니다.

## 설치하기 (갤럭시 탭·휴대폰)
1. 기기에서 https://github.com/ij17838-creator/PBS/releases/tag/apk-latest 를 엽니다.
2. `PBS-app.apk`를 눌러 내려받고, 다 받아지면 엽니다.
3. 처음 한 번은 "출처를 알 수 없는 앱 설치"를 허용하라는 창이 뜹니다. 내려받은 앱(Chrome·삼성 인터넷·내 파일)에 허용을 켭니다.
4. 설치 → 열기. 새 버전이 올라오면 같은 방법으로 받아 **덮어 설치**합니다(지우지 않아도 됨, 자료 유지).

> 주의: 앱 안의 자료는 브라우저(Chrome)에서 쓰던 자료와 따로 저장됩니다. 옮기려면 브라우저에서 "백업 내보내기" → 앱에서 "백업 불러오기"를 합니다.
> 앱을 **삭제하면 앱 안 자료도 지워집니다.** 지우기 전에 백업을 내보내세요.

## 알림창 ＋1 버튼 (빈도 측정)
1. 표적행동 정의에서 측정 방법을 "빈도"로 고릅니다.
2. 기초선(또는 중재) 회기 줄의 **알림창 ＋1 켜기**를 누릅니다. 처음에는 알림 허용을 묻습니다 → 허용.
3. 이제 다른 앱(수업 자료)을 띄워 둔 채, 화면 위에서 아래로 내려 알림의 **＋1**을 누릅니다. 누를 때마다 짧게 진동하고 알림에 "지금 n회 · 마지막 시각"이 바뀝니다.
   - 잘못 눌렀으면 **−1**, 회기가 끝나면 **끝**.
4. 앱으로 돌아오면 그 회기의 측정값이 늘어 있고, 아래에 "알림창 기록 n건: 누른 시각"이 남습니다.

## 화면 자동 업데이트 (다시 설치하지 않아도 됨)
- 앱은 열릴 때(그리고 다시 앞으로 나올 때, 5분에 한 번까지) 인터넷의 최신 웹앱(https://ij17838-creator.github.io/PBS/)을 받아 둡니다.
- 받으면 위에 "새 화면 버전이 있어요 · 지금 적용"이 뜹니다. 누르면 바로 바뀌고, 안 눌러도 다음에 앱을 열 때 바뀝니다.
- 앱 안 자료는 그대로입니다(주소가 같음). 인터넷이 없으면 마지막으로 받은 화면을 씁니다.
- 받은 화면이 열리다 멈추면, 다음에 앱을 열 때 설치 파일에 든 화면으로 돌아가고 그 버전은 다시 받지 않습니다.
- 다시 설치해야 하는 때: 위젯·알림·빠른 설정처럼 안드로이드 쪽(android 폴더)이 바뀐 경우만. 새 apk를 깔면 그 apk의 화면부터 다시 시작합니다.

## 앱이 꺼져 있어도 측정 (앱 밖 측정: 위젯·빠른 설정·알림창)
앱을 실행하지 않았거나, 최근 앱에서 지웠거나, 재부팅한 뒤에도 버튼을 누르면 바로 기록됩니다. 빈도·지속시간만 됩니다.
1. 미리 한 번: 앱에서 기초선(또는 중재) 화면 → 회기 목록 아래 **앱 밖 측정 켜기**. (학생·단계·측정 방법이 이 화면 기준으로 정해짐)
2. 같은 줄의 **위젯 놓기**(홈 화면에 'PBS 측정' 위젯), **빠른 설정 추가**(화면 위에서 두 번 내린 버튼 판에 'PBS 측정' 타일).
   - 버튼 창이 안 뜨면: 홈 화면 빈 곳 길게 누르기 → 위젯 → PBS 기록 / 빠른 설정 판의 연필(편집) → PBS 측정을 끌어 놓기.
3. 수업 중:
   - 빈도: 위젯 큰 **＋1**, 빠른 설정 타일, 알림의 **＋1** 중 아무거나. 첫 ＋1에서 새 회기가 시작됩니다. 잘못 누르면 **−1**, 끝나면 **회기 끝**. 0회인 회기는 **회기 시작** → **회기 끝**.
   - 지속시간: **행동 시작** → **행동 끝**(위젯·알림에 흐르는 시간 표시). 끝나면 **회기 끝**.
   - 회기 끝을 잊어도 날짜가 바뀌면 다음 버튼부터 새 회기가 됩니다.
4. 앱을 열면 누른 날짜·시각으로 새 회기가 만들어지고 측정값이 들어갑니다(공유 프로젝트면 서버에도 올라감).
   - 빈도: 측정값 = 횟수, "알림창 기록 n건: 누른 시각".
   - 지속시간: "앱 밖 기록 n건: 시작~끝". 단위에 '/회'만 있으면(예: 분/회) 1회 평균 분, 아니면 총 분(예: 총 분/회기). 측정값은 이 기록으로 다시 계산되므로 손으로 고친 값은 다음 버튼 때 바뀝니다.
- ABC 관찰에서도 쓸 수 있습니다: ABC 화면의 **앱 밖 측정 켜기** → 그 뒤 ＋1마다 발생 시각이 한 행씩 쌓이고(B 칸은 표적행동 이름), A·C는 나중에 앱에서 채웁니다. −1은 마지막으로 찍은 빈 행을 지웁니다. 측정 대상은 한 번에 하나라서, 켜면 기초선·중재 쪽 대상은 꺼집니다.
- 알림 권한을 끄면 알림 버튼만 안 보이고 위젯·빠른 설정은 됩니다.
- 잠금 화면에서 빠른 설정 타일이 눌리는지는 기기 설정(잠금 상태에서 빠른 설정 사용)에 따라 다릅니다.

## 만드는 방법 (개발 메모)
- 저장소에 index.html·android 폴더가 바뀌어 main에 올라가면 GitHub Actions("안드로이드 앱 빌드")가 .apk를 만들어 Releases `apk-latest`에 올립니다(약 5~10분).
- 직접 만들 때: `npm ci && npm run sync` 후 `android` 폴더를 Android Studio로 열거나 `cd android && ./gradlew assembleDebug`.
- 서명 키 `android/app/pbs-debug.keystore`는 시험판 전용입니다. 플레이스토어 출시용 키는 따로 만들어 비밀로 보관해야 합니다.

## 브라우저와 연동 (서버 공유)
1. 브라우저에서 프로젝트를 열고 **공유 시작** → 공유 ID·코드가 나옵니다.
2. 앱에서 **구글로 로그인**(안드로이드 계정 선택 창) → 홈의 **공유 ID·코드로 받기**에 넣습니다.
3. 그 뒤로 그 프로젝트는 앱과 브라우저에서 실시간으로 맞춰집니다.
- 앱 로그인은 Firebase에 등록한 안드로이드 앱(패키지 `io.github.ij17838creator.pbs`, 시험판 키 SHA-1 `9E:52:A9:4E:71:F6:54:37:B4:06:27:8A:1B:AD:09:AF:07:D4:9D:79`)과 index.html의 `GOOGLE_WEB_CLIENT_ID`로 동작합니다. 출시용 키를 새로 만들면 그 SHA-1도 Firebase에 추가해야 합니다.
